# Master Phase Blueprint Catalog — SupplyChain-Guard

> Authoritative roadmap for all development phases. Each phase maps to a specific layer in the defense-in-depth pipeline.

| Phase | Title | Description | Key Deliverables | Status |
|-------|-------|-------------|-----------------|--------|
| **P0** | Static AST Script Scanner | `syn`-based Rust AST visitor for `build.rs` and `serde_json` parser for `package.json` lifecycle hooks. Detects command execution (`Command::new`), network calls (`TcpStream::connect`), credential access (`env::var` for sensitive keys), and suspicious filesystem reads (`~/.ssh/`, `~/.aws/`, `.env`) | `crates/scanner/`, `supplychain-guard scan` CLI subcommand, JSON + human-readable output | ✅ Complete |
| **P1** | Process Isolation Enforcer | OS-native sandbox wrapper. **Windows:** Job Objects (`CreateJobObjectW`, `SetInformationJobObject`) + UI restrictions. **Linux:** `unshare` namespaces (PID/NET/MNT) | `crates/sandbox/`, platform-specific modules under `src/win/` and `src/linux/`, `supplychain-guard exec` CLI subcommand | ✅ Complete |
| **P2** | Network & Env Sanitizer | Network deny-by-default enforcement inside the sandbox. Environment variable stripping for known credential patterns (`AWS_*`, `GITHUB_TOKEN`, `NPM_TOKEN`, `SSH_AUTH_SOCK`). Configurable allowlists for legitimate env vars | Integrated into `crates/sandbox/`, env sanitization module, network policy config | ✅ Complete |
| **P3** | CI/CD Pipeline Mode & Governance | Structured JSON output, configurable severity thresholds, non-zero exit codes for CI gating, SARIF report generation, SHA-256 script hashing engine, pre-commit hook installer | SARIF exporter, GitHub Actions workflow (`action.yml`), pre-commit installer | ✅ Complete |
| **P4** | Advanced AST & Hardening | Dynamic FFI AST inspection (`dlsym`, `LoadLibrary`, `GetProcAddress`), raw socket/HTTP crate import detection (`socket2`, `reqwest`, `ureq`), obfuscated byte array / hex sequence literal detection | `crates/scanner/src/rust_scanner.rs`, `init-config` policy generator | ✅ Complete |
| **P5** | Package Manager Integration | Transparent wrappers: `cargo-guard` Cargo subcommand (intercepting `cargo build` to inject scan + sandbox) and `npm-install` subcommand (intercepting `npm install` lifecycle hooks) | `crates/cargo-guard/`, `supplychain-guard npm-install` subcommand, integration test suite | ✅ Complete |
| **P6** | Security Audit Telemetry Engine | Structured JSONL execution audit log, scan finding event recording, sandbox runtime telemetry, policy recommendation auto-tuner CLI | `crates/audit/`, `supplychain-guard audit` subcommand, audit test suite | ✅ Complete |
| **P7** | Workspace Integrity & Build Mutation Gating | Pre/post-build SHA-256 workspace file snapshotting, diff verification, unauthorized source mutation detection, workspace integrity CLI | `crates/integrity/`, `supplychain-guard verify-integrity` subcommand, integrity test suite | ✅ Complete |
| **P8** | SBOM Security Attestation Engine | CycloneDX v1.4 and SPDX v2.3 compliant JSON attestation manifest generator summarizing build script hashes, AST findings, and sandbox policies | `crates/sbom/`, `supplychain-guard sbom` subcommand, SBOM test suite | ✅ Complete |
